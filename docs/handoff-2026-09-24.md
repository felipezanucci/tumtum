## 3. The traps this session paid for

- **The app stated something false about its own state, again, and it cost
  an afternoon.** A card made over a video kept only its first frame, and
  on the next visit it restored that frame *as a photo*. It looked identical, and
  every network received a still. Three plausible fixes went in first (9:16,
  codec, frame rate, launch flags) before Felipe, tapping the phone, saw the
  pattern: *"toda vez que eu subo o vídeo na hora, ele toca"*. **When a
  bug appears only on the second visit, suspect what was persisted, not
  the pipeline.**
- **Snap's 300 dp sticker limit is in the SDK docs, and Creative Kit Lite
  does not enforce it.** Fitting inside it made the card small. The card now
  takes the screen width, with its foot at 76% of the height (above
  Snapchat's friends row, measured on Felipe's phone).
- **A dark wash behind a movable sticker reads as a box**, however its edges
  are faded. Movable stickers carry only shadows. The burned video keeps the wash.
- **Portal uploads fail silently on bad files.** Snap's *"Unknown upload
  error"* was a file named `.mp4.mp4` (Windows hides extensions), with a
  variable frame rate, recompressed by WhatsApp. Re-encoded with ffmpeg
  (`pip install imageio-ffmpeg` gives a static binary), it uploaded at once.
  Record on the phone, and move files by cable or Drive, never WhatsApp.
- **The TikTok SDK adds `AD_ID`**, which would change the Play data-safety
  answers for a share button. The intent is built by hand instead.
- **`aiosqlite` newer than 0.20 hangs under SQLAlchemy 2.0.23.** CI pins
  `"aiosqlite<0.21"`. The feed tests run real SQL on in-memory SQLite with
  `@compiles` hooks for UUID and JSONB.
- **Workflow**: `pkill -f` on a pattern that matches your own shell kills the
  shell. Commit messages written to the scratchpad need unique file names,
  or a failed step commits a stale message. A PR is opened only after the
  last push, and it is re-read from GitHub before its link is sent. Anything
  after a merge gets a new PR from a branch reset to `main`.
