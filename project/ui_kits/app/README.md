# UI Kit — App TumTum (Android)

Fluxo interativo do core loop: **Ao vivo → A revela → Escolha → Card**. Clique nos CTAs para avançar; a escolha da pele no passo 3 muda o card final.

Telas recriadas de `TumTum-App.dc.html` (rodadas 1–2, ago/2026). Compostas com os primitives do sistema (Button, Chip, MetaLabel, HeroNumber, BpmCurve, MomentRow, ShareCard, WordmarkPlate). Superfície preta nas telas de show (captura, revela), branca na escolha. Sem ícones — rótulos de texto, decisão v0.5.
