Rótulo/carimbo retangular (radius 0 — pôster, não pílula) em caixa alta com tracking. É como o amarelo entra: "27 MOMENTOS", "MELHOR FONTE", horário do pico.

```jsx
<Chip variant="flash">27 MOMENTOS</Chip>
<Chip variant="outline">6H38</Chip>
<Chip variant="scrim">LOLLAPALOOZA — DIA 2 · 23H47</Chip>
```

`scrim` é o único uso aprovado de transparência: chip sobre foto/vídeo.
